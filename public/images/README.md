# Image slots

These photographs are placeholders. Replace a file with the owner’s photography and keep the filename. The site reads them from this folder; no code change is required if the filename stays the same.

They are illustrative stock, not projects of Precision Cabling & Automation, and not the premises. Do not add a caption that names a client, a site, or a result.
